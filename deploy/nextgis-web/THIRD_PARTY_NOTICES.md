# Componentes externos — NextGIS Web CE

Este serviço GeoMoz reutiliza a imagem oficial **NextGIS Web Community Edition**,
desenvolvida e mantida pela NextGIS.

- Código original: https://github.com/nextgis/nextgisweb
- Configuração/imagem oficial: https://github.com/nextgis/nextgisweb_ce
- Imagem Docker: `nextgis/nextgisweb-ce:26.10.0`
- Licença do NextGIS Web: **GNU General Public License v3.0**
- Texto integral: https://www.gnu.org/licenses/gpl-3.0.html

Os avisos de autoria, licenças e código-fonte da distribuição original
permanecem associados à imagem oficial. O GeoMoz não remove nem altera
esses avisos. Serviços GeoMoz e componentes próprios comunicam com o
NextGIS Web por HTTP/REST; não se trata de uma redistribuição do código do
servidor sob identidade própria.

Este ficheiro documenta a proveniência e **não** substitui os textos de
licença e avisos efectivamente incluídos na imagem e nos pacotes upstream.
